# summary_md
## 讲座背景与主题
本视频为哈尔滨工业大学举办的“DeepSeek技术前沿与应用”专题讲座回放。主讲人通过PPT演示，系统梳理了从传统生成式预训练Transformer到大语言模型（LLM）的技术演进路径。讲座内容涵盖了自然语言处理领域的关键突破，包括指令微调（Instruction Tuning）、零样本提示（Zero-shot）以及强化学习在模型优化中的应用。

## DeepSeek技术架构解析
视频重点展示了DeepSeek系列模型的迭代历程，详细对比了V1至R1版本及最新的GRPO（Group Relative Policy Optimization）算法。画面中出现的架构图解释了模型如何通过价值网络进行决策评估，以及如何利用奖励机制引导模型输出更符合人类意图的结果。此外，还提及了贝叶斯公式等数学基础在多模态理解中的作用。

## 行业观点与社会影响
除了硬核技术拆解，讲座还探讨了AI对未来的广泛影响。涉及话题包括开源生态的竞争格局、大模型在医疗排班等垂直场景的应用潜力，以及对AGI（通用人工智能）发展阶段的展望。现场互动热烈，观众就数据安全、腾讯元宝竞品差异及就业替代等问题进行了讨论。
