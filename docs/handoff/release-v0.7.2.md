## 这个版本解决什么问题

**「发布记录」那一块，字小到像脚注，撤回像个注释。**

原话是「增大这部分的字体，把『撤回』两个字进行变红和高亮」。截图里一行记录挤成三截：左边日期被一个 18px 的固定宽度拦腰断成 `10-27` / `18:00` 两行，中间正文 11.5px，右边「撤回」是 9px 灰字——**看不出那是个能点的操作**，更像一句免责声明。

## 改了什么

| 位置 | 改前 | 改后 |
|---|---|---|
| 正文 `.x` | 11.5px | **13.5px**，行高 1.5 |
| 日期 `.n` | 18px 定宽，挤成两行 | **11.5px、不换行**，按内容取宽 |
| 「撤回」 | 9px 灰字，无底无框 | **12px 粗体红字 + 14% 红底 + 红边框**，hover 加深 |
| 块标题 | — | 10.5px |

字号只作用于 `#hist-list`，左边的版本列表仍是原尺寸——**要放大的是「我发过什么」，不是「我有几版」**，两处共用一套 `.v` 规则，直接改会把整页撑肿。

## 红色不是随手挑的

新加一个语义变量 `--danger`，两套皮肤各取一个值：

- 近黑底（默认皮肤）：`#FF6B6B`，压在 14% 红底上 **5.41:1**
- 近白底（异客巡展）：`#B42318`，**5.20:1**

都过 WCAG AA 的 4.5:1。同一个红在两种底上不能共用：近黑底上压深会发闷，近白底上提亮会刺眼——这也是这套皮肤系统里 `--acid` / `--acid-tx` 分家的同一条理由。

## 验证

- `node tests/frontend_test.js`：**225 通过 / 0 失败**
- `tests/smoke_test.py`：**离线 40/40、HTTP 49/49**
- 新增 8 条断言，**读的是 `getComputedStyle` 的结果**，不是源码里写了什么：颜色必须走 `--danger` 这个口子、`--danger` 本身必须是红（红通道压过绿蓝 1.5 倍以上）、字号不小于 12/13px、底色不是透明的、发布记录必须比版本列表大。
  - jsdom 不展开自定义属性，`color:var(--danger)` 读回来就是这串原文。所以分两步钉：**引用对不对** 和 **变量值红不红**——只钉一步都能被「变量改错但照样引用」骗过去。
- 真机 Chrome 渲染核对（无头 + CDP，非 jsdom）：实测 `color: rgb(180,35,24)`、`background: rgba(180,35,24,.14)`、按钮 12px、正文 13.5px，日期一行排完。
