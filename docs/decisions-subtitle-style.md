# 字幕样式系统 · 需求决策记录

> 状态：已逐项确认。拷打强度：深挖。记录方式：结论 + 理由 + 边界。
> 对应规划：docs/aegis/plans/2026-11-13-subtitle-style-system.md

| 决策 | 选择 | 结论与理由 |
|---|---|---|
| Q3 功能作用域 | A | 样式统一驱动设置预览、字幕导出与硬字幕烧录；避免调完样式后输出不生效。 |
| Q4 对齐方式 | A | 功能对齐 VideoCaptioner，界面沿用 VideoWorkbench 现有设计体系。 |
| Q5 配置归属 | B | 全局默认 + 单视频覆盖，兼顾统一效率与个别素材排版。 |
| Q6 字幕格式 | C | ASS 携带完整样式；SRT 保持纯文本，由用户选择导出格式。 |
| Q7 任务生效时机 | A | 任务启动时保存样式快照，保证已启动任务可复现。 |
| Q8 全局继承 | A | 无覆盖项目跟随全局；有覆盖项目独立，可手动恢复继承。 |
| Q9 参考文件兼容 | A | 只对齐功能，使用 VideoWorkbench 自有样式结构，不兼容 VideoCaptioner 文件。 |
| Q10 排布 | A | 支持仅主字幕、仅副字幕、主字幕在上、副字幕在上。 |
| Q11 字段范围 | C | 完整 ASS 样式：基础字段、粗斜体、阴影、背景、对齐、边距、透明度、旋转、缩放、模糊等。 |
| Q12 预设管理 | B | 选择、新建、重命名、删除、复制、打开样式文件夹；现有 JSON 导入导出保留。 |
| Q13 预览内容 | C | 真实视频帧与固定演示图并存，无视频时回退演示内容。 |
| Q14 分辨率 | A | 横屏 1920×1080、竖屏 1080×1920 为参考尺寸，相关参数等比缩放。 |
| Q15 预设编辑 | A | 预设作为模板；当前配置修改不自动写回，覆盖或另存必须显式操作。 |
| Q16 字体 | A | 使用系统字体；缺字体时使用明确后备字体并提示，不打包字体文件。 |
| Q17 预览方式 | C | 快速近似预览 + 按需精确预览；精确预览、ASS 和烧录共用样式模型。 |
| Q18 编辑入口 | A | 设置页管理全局与预设；字幕模块管理当前视频覆盖并显示作用域。 |
| Q19 保存方式 | A | 普通字段自动保存；预设覆盖与另存仍显式操作。 |
| Q20 升级迁移 | A | 保留当前默认外观；已有配置迁移为等效样式，不改变既有输出。 |
| Q21 平台 | A | 本期只验收 Windows 桌面版。 |
| Q22 批量操作 | A | 一次只配置一个视频，不做批量套用或全量清除覆盖。 |
| Q23 软字幕 | A | MP4 软字幕继续使用 mov_text，明确不保留样式；完整样式承诺范围为 ASS、精确预览与硬字幕。 |

## 补充约束

- 项目覆盖是整份配置覆盖，不做逐字段继承。
- 查看项目不创建覆盖，第一次实际保存才创建。
- 无效输入保留在编辑态并显示错误，不覆盖上一份有效配置。
- SRT/VTT 不携带样式；NLE 既有「字幕样式不跟随」边界不变。
- 不做批量套用，不承诺 macOS/Linux，不创建 git commit/push。
