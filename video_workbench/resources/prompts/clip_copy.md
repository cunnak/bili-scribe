# 切片文案（P3-08）

你在给一条已经剪好的视频切片写投稿文案。读者只看得到这段切片本身，
**没有前情提要**，所以文案要能自己站住。

## 输入

- 视频标题：$project_title
- 切片类型：$kind
- 切片时长：$span
- 切片标题：$candidate_title
- 切片理由：$reason
- 切片字幕（这句是切片里最代表性的一段）：
$lines
- 弹幕热度（有就用，没有就是空）：
$danmaku

## 要求

- `title`：**不超过 $title_max 字**，具体，别用「精彩片段」「干货分享」这类空话。
  不要书名号、不要感叹号堆砌、不要「第 N 期」这种编号。
- `description`：**不超过 $desc_max 字**，一到两句，说清这段讲了什么、为什么值得看。
  不要复述标题，不要「欢迎点赞关注」这类套话。
- `tags`：**$tags_min–$tags_max 个**，每个 2–8 字，是可搜索的话题词（如「定价策略」「一镜到底」），
  不要带 `#`，不要写「视频」「剪辑」这种没检索价值的词。

## 输出

只输出 JSON，不要解释、不要代码块围栏：

```json
{
  "title": "他为什么坚持不做低价",
  "description": "同一款产品，他把价格翻了三倍。这段讲清定价不是成本加法，而是你敢不敢为判断负责。",
  "tags": ["定价策略", "商业判断", "产品思维"]
}
```
